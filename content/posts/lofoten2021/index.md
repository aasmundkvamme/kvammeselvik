# Laurdag 2. oktober
Kombinert bursdag(ar) og bryllpsdag i lavvoen hos Vegard, Lise-Lotte, Sigmund og Jesper. Etterpå guida tur rundt Kvalnes og Gimsøya. Ungdommen laga middag i Tore Hjorts vei.

# Sundag 3. oktober
Gudsteneste i Buksnes kirke, og så på tur med Johannes og Vigdis.

{{< beautifulfigure src="PA030219-1024x576.jpg" caption="" width="100%" class="center" >}}

Vi starta frå [Innersand](https://norgeskart.no/#!?project=norgeskart&layers=1002&zoom=11&lat=7554551.21&lon=421935.58), heilt nord på Moskenesøya:

{{< beautifulfigure src="2021-10-07-20_40_23-GPS-Visualizer_-Leaflet-Maps-output.png" caption="" width="100%" class="center" >}}

Litt ulike idear til føremiddagstur gjorde at vi køyrte til [Uttakleiv](https://norgeskart.no/#!?project=norgeskart&layers=1002&zoom=12&lat=7567298.99&lon=438721.33).
